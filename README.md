 Iris Data Visualization Dashboard
This project was created entirely in **Google Colab** — my favorite place for quick experiments and clean visualizations.
After taking a short break from projects, I wanted to refresh my data-visualization basics, so I revisited the timeless **Iris dataset** and built a simple dashboard using **Matplotlib** and **Seaborn**.

 Project Overview
The goal was to explore how the petal and sepal measurements vary among Iris species and to visualize those patterns clearly.
Using Colab made it easy to iterate, plot, and tweak visuals in real time without any setup hassle.

I created:

📊 Boxplots to compare distributions across species
🎯 Scatterplots to show correlations between features
🖼️ Subplots to arrange multiple insights into one dashboard-style layout

Tools & Libraries

Google Colab Notebook
Python 3
Matplotlib (for customized plots)
Seaborn (for statistical visualizations)
Pandas / NumPy (for data handling)

What I Learned

Combining multiple plots using subplots for a dashboard feel
Controlling plot aesthetics in Seaborn and Matplotlib
How visual storytelling can make even simple datasets insightful
And honestly — how refreshing it feels to get back into coding after a small break 😄
